# Freight Rate Prediction

Predicts posted freight rates for truckload shipments.
Submission for the Spotter Machine Learning Engineer assessment.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Place the provided data files in `data/`:
`train_test.csv`, `validation.csv`, `validation_predictions_template.csv`
